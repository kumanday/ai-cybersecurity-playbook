# Security Policy

## Exercise targets

`exercises/sample-vuln-app/` and `exercises/sample-vuln-js/` are intentionally
vulnerable training applications. Their planted vulnerabilities and fake secret
values are expected. Run them only on localhost in a disposable environment.

## Reporting problems

Use a GitHub issue for incorrect documentation, broken exercise behavior, or a
security problem that contains no sensitive information.

Do not put undisclosed vulnerabilities, credentials, customer data, or details
about systems you do not own in a public issue. Send sensitive reports to a
repository maintainer through an approved private Trilogy channel.

Reports should include the affected file or URL, reproduction steps, observed
impact, and a suggested fix when one is known.
